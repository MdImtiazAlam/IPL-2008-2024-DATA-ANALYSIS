# IPL-2008-2024-DATA-ANALYSIS
# IPL Data Analysis using Python & Pandas

## Overview
This project is an exploratory data analysis (EDA) of the Indian Premier League (IPL) dataset using Python and the pandas library. It uncovers trends, player performance, team statistics, and various insights from historical IPL match data.

## Objectives
- Analyze team and player performance
- Explore winning patterns
- Visualize match statistics
- Gain insights from past IPL seasons

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The data used in this analysis includes:
- `matches.csv` — details of IPL matches
- `deliveries.csv` — ball-by-ball data

> You can download the dataset from [Kaggle - IPL Dataset](https://www.kaggle.com/datasets)

## Key Analysis Performed
- Top winning teams and their winning percentages
- Most successful players (batsmen and bowlers)
- Toss impact on match results
- Runs scored per season
- Performance by city and stadium
- Strike rates and economy rates
